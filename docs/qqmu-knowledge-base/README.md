# QQ沐编程 知识库

抓取自 [QQ沐编程](https://www.qqmu.com/) 全站内容，用于智能客服的 RAG 问答。

**数据规模**：2095 篇文章 · 73 个页面 · 34 个分类 · 288 个标签
**抓取来源**：WordPress REST API (`/wp-json/wp/v2/`)
**生成日期**：2026-08-07

---

## 文件清单

### 必传

| 文件 | 大小 | 内容 |
|---|---|---|
| `kb_main.md` | 4 KB | **站点总览**：34 个栏目导航表、关键词→栏目映射表、热门标签。让模型理解站点结构 |

### 二选一（或都传）

| 文件 | 大小 | 切分后 | 适用场景 |
|---|---|---|---|
| `kb_index_lite.md` | 511 KB | ~742 片段 | **轻量版**：全部 2095 篇的标题+链接+简介。做「关键词 → 文章地址」推荐足够，成本低、入库快 |
| `kb_cat_*.md`（34 个） | 共 2.0 MB | ~12,900 片段 | **全文版**：按栏目拆分，含文章正文。能回答文章内部的具体技术问题 |

### 可选

| 文件 | 内容 |
|---|---|
| `kb_pages.md` | 网站独立页面（关于、导航等） |
| `kb_prompt.md` | **配置指南**（给运维看的，**不要上传到向量库**） |
| `scripts/` | 抓取与生成脚本，用于将来刷新数据 |

## 快速开始

### 第一步：先用轻量版验证

在管理后台「知识文档」上传：

1. `kb_main.md`
2. `kb_index_lite.md`

约 750 个片段，入库快。然后到「聊天预览」测试：

- 「有没有登录页面的模板？」
- 「Python爬虫相关的文章」
- 「404页面怎么做」

如果能准确给出文章链接，说明检索链路正常。

### 第二步：按需补充全文

需要回答文章内部细节时，再上传对应栏目的 `kb_cat_*.md`。

按文章数排序的前几个栏目（信息量最大）：

| 文件 | 篇数 |
|---|---|
| `kb_cat_HTML项目.md` | 324 |
| `kb_cat_电脑软件.md` | 192 |
| `kb_cat_网页特效.md` | 187 |
| `kb_cat_技术教程.md` | 167 |
| `kb_cat_PHP项目.md` | 156 |
| `kb_cat_C语言小案例.md` | 140 |

> 不必一次全传。全部上传约 12,900 个片段，embedding 约 320 万 token
> （阿里 `text-embedding-v3` 约 ¥1.6，耗时 5-10 分钟）。

## 实测切分效果

用本项目的结构感知切分器验证（`chunk_size=800`）：

| 文件 | 字数 | 片段数 | 带标题路径 | 含文章链接 |
|---|---|---|---|---|
| `kb_main.md` | 4,523 | 9 | 100% | 66% |
| `kb_index_lite.md` | 510,707 | 742 | 100% | **98%** |
| `kb_cat_*.md` 合计 | ~2.0M | 12,900 | 100% | 72% |

「含文章链接」指该片段内出现 `qqmu.com/xxx.html`，模型能直接引用出来。
正文里的每个小标题都补了一行「（本节出自：链接）」，所以即使命中的是
文章中间的某个小节，也能给出出处。

### 第三步：调参数

详见 [kb_prompt.md](kb_prompt.md)。要点：

| 参数 | 建议值 |
|---|---|
| 切分策略 | 结构感知 |
| 标题前缀 | 开启 |
| Chunk Size | 800 |
| Top K | 6~8 |
| 相似度阈值 | **0.35~0.45**（用户搜索词短，阈值高会误拒答） |
| Temperature | 0.2~0.3 |

## 文件格式说明

每篇文章用 `【标题】` 包裹，配合本项目的**结构感知切分器**，每篇文章会成为
独立片段，并自动带上「栏目 > 文章名」的标题路径：

```
【IDEA中遇到Git Log界面不显示问题的解决步骤】
文章地址：https://www.qqmu.com/6564.html
所属栏目：BUG专区
标签：git
发布日期：2026-01-05

IntelliJ IDEA 中遇到 Git Log 界面不显示问题的解决方案…

### 问题描述
- 在 IntelliJ IDEA 中，Git 的 Log 界面没有任何显示。
…
```

实测切分结果：**100% 的片段都带标题路径**，文章链接就在片段内，
模型能直接引用出来。

## 已做的内容处理

| 处理 | 原因 |
|---|---|
| 超长文章正文截断到 1600 字 | 最长一篇 6.2 万字（樱花特效），几乎全是 JS 代码，塞进向量库只会产生噪音 |
| 代码块只保留开头 260 字 | 同上，并注明「完整代码见原文」 |
| 过滤版权声明/转载提示/公众号引导 | 站点通用噪音，每篇都有，会干扰语义匹配 |
| 保留 Markdown 小标题层级 | 让切分器能识别文章内部结构 |

## 刷新数据

网站持续更新，建议每季度重新生成：

```bash
cd scripts
python3 fetch_qqmu.py      # 抓元数据    → qqmu_raw.json
python3 fetch_content.py   # 抓正文      → qqmu_full.json
python3 build_kb.py        # 生成全文版   → kb_main.md + kb_cat_*.md
python3 build_index.py     # 生成轻量版   → kb_index_lite.md
```

脚本只依赖 Python 标准库，无需安装任何包。全流程约 3-5 分钟。

重新入库前记得先在「知识文档」里删掉旧文件。
